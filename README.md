# POS App

Aplicación de punto de venta offline desarrollada con Flutter, Dart y Drift/SQLite.

## Funciones actuales

- Catálogo de productos
- Registro de productos con SKU y código de barras
- Precios de compra y venta
- Stock inicial
- Stock mínimo
- Historial de movimientos de inventario
- Edición de productos
- Ajuste manual de stock

## Tecnologías

- Flutter
- Dart
- Drift
- SQLite
- Material 3
